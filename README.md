# Ashoka Society for International Trade & Foreign Policy – Website

Website for the Ashoka Society for International Trade & Foreign Policy (ASITFP), a student society at Ashoka University. It introduces the society and hosts its blog and latest updates.

## Pages

- **Home** – introduction and highlights
- **About** – the society and what it does
- **Blog** – articles on trade and foreign policy
- **Updates** – events and announcements

## Tech stack

React · TypeScript · Vite · Tailwind CSS · shadcn/ui

## Getting started

```bash
npm install
npm run dev
```

## Project structure

```
src/pages/        Home, About, Blog, Updates, NotFound
src/components/   layout, navigation and UI components
```
